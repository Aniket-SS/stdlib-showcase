# stdlib Showcase

🔗 **Live demo**: https://aniket-ss.github.io/stdlib-showcase/

A GSoC 2026 showcase of stdlib-js demonstrating:
- **NDArray Visualizer** — create, slice and operate on ndarrays interactively
- **Matrix Operations** — dot product and norm of matrix multiply
- **Gold Price Analysis** — NSE GOLDBEES data analyzed via stdlib stats

## Run locally
npm install && npm run build
npx serve .
